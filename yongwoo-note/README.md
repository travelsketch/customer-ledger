# 용우노트 (휴대폰 웹앱)

삼성 노트처럼 쓰는 **휴대폰 노트**입니다. 폴더로 나누고, 체크리스트로 할 일을 적고,
손가락이나 S펜으로 약도·서명을 그려 넣고, 사진과 PDF를 붙이고, A4로 깔끔하게 인쇄합니다.
자료는 기본적으로 **이 기기의 브라우저 저장소(IndexedDB)에만** 저장되며 어디로도 보내지 않습니다.
원하면 **구글 드라이브 자동 연동**으로 PC와 폰의 노트를 맞출 수 있고, 인터넷이 없어도 열립니다.

- 주소: **https://travelsketch.github.io/customer-ledger/yongwoo-note/**
- 폰에서 크롬·삼성 인터넷으로 위 주소를 연 뒤 메뉴의 **‘홈 화면에 추가’**를 누르면 앱처럼 전체 화면으로 열립니다.
  (아이콘을 길게 누르면 **새 노트** 바로가기도 나옵니다.)

## 📝 노트 목록 화면

- **폴더** — `전체`, `⭐ 즐겨찾기`, `업무`, `고객`, `농장`, `개인`, `🗑 휴지통`이 기본으로 있고
  **＋ 폴더**로 원하는 이름(예: 건강)을 더할 수 있습니다. 폴더를 지우면 그 안의 노트는 **개인** 폴더로
  옮겨지고 노트 자체는 지워지지 않습니다.
- **📌 핀 고정** — 노트 오른쪽 위 📌 를 누르면 목록 맨 위 ‘고정한 노트’에 따로 모입니다.
- **⭐ 즐겨찾기** — 위 폴더 줄의 `⭐ 즐겨찾기`에서 별표한 노트만 봅니다.
- **보기 전환** — 위쪽 `☰`(카드 격자) / `▦`(목록) 버튼으로 바꿉니다. 선택한 보기는 기기에 기억됩니다.
- **검색** — 🔍 를 누르고 단어를 넣으면 **제목·본문·태그·첨부파일 이름**을 한 번에 찾습니다(띄어쓰기로 여러 단어).
- **정렬** — `최신순` / `제목순` 을 눌러 바꿉니다.
- **선택** — `선택`을 누르면 노트를 여러 개 골라 **한꺼번에 인쇄**하거나 **휴지통으로** 옮길 수 있습니다.
- **새 노트** — 오른쪽 아래 큰 `＋` 버튼.

## ✍️ 편집 화면

- **제목 + 본문** — 제목을 적고 아래 본문에 이어서 씁니다. 적는 대로 자동 저장되고
  위쪽에 `저장됨 14:20` 처럼 표시됩니다. `저장` 버튼을 눌러도 됩니다.
- **서식** — 아래 공구줄에서 **굵게(B)**, *기울임(I)*, 밑줄(U), **형광펜(🖍)**, **글자 크기(가)**,
  **글머리 기호(•≡)**, **체크리스트(☑)** 를 쓸 수 있습니다.
  글자를 먼저 선택한 뒤 누르면 그 부분에 적용됩니다.
- **체크리스트** — ☑ 를 누르면 `□` 줄이 생깁니다. 글자를 적고 네모를 누르면 `✓` 로 바뀌며
  줄에 취소선이 그어집니다. 한 번 더 누르면 풀립니다.
- **손글씨·약도·서명(✏️)** — 손가락이나 S펜으로 그리고 **노트에 넣기**를 누르면 본문에 그림으로 들어갑니다.
  펜 색 5가지, 굵기 3가지, 지우개, 되돌리기, 전체 지우기, 줄노트 배경을 지원합니다.
- **사진·PDF(🖼)** 와 **카메라(📷)** — 갤럭시 카메라가 바로 열립니다(`capture="environment"`).
  사진은 저장할 때 **긴 변 최대 1600px, JPEG 품질 80%** 로 자동으로 줄입니다(원본이 이미 작고 가벼우면 그대로).
  PDF는 압축하지 않고 그대로 보관합니다. 붙인 사진은 눌러서 크게 보고 **본문에 넣기**·내려받기·삭제를 할 수 있습니다.
- **페이지 스타일(📄)** — 흰색 / 연노랑 / 연파랑 / 줄노트 중에서 노트마다 고릅니다.
- **노트 메뉴(⋮)** — 폴더 바꾸기, 페이지 스타일, **인쇄 미리보기**, **텍스트(.txt) 내보내기**, **노트 복제**, **휴지통으로**.

## 🖨 인쇄

`인쇄 미리보기`에서 지금 노트(또는 선택한 여러 노트)를 A4 한 장에 맞춰 보여 줍니다.
`사진 함께 인쇄`와 `첨부 파일 이름 표시`를 켜고 끌 수 있고, `🖨 A4 인쇄`를 누르면 인쇄 창이 열립니다.
맨 위에 **용우노트** 제목, 출력 일시, 노트 제목·폴더·수정일, 본문(체크 상태 포함), 사진, 태그가 들어갑니다.

## 💾 백업·복원

- **JSON 백업** (☰ → JSON 백업 내려받기) — 노트·폴더·첨부(사진·그림·PDF)를 파일 하나
  `용우노트-백업-2026-11-23.json` 으로 내려받습니다. 컴퓨터에 옮겨 두면 안전합니다.
- **복원** (☰ → 백업 파일 복원) — 내려받은 `.json` 파일을 고르면 **지금 노트에 더합니다.**
  같은 노트는 최근 것으로 하나만 남고, 기존 노트가 지워지지는 않습니다.
- **텍스트로 내보내기** (노트 메뉴 ⋮) — 그 노트만 `.txt` 로 저장합니다. 체크 상태는 ☐/☑ 로 적힙니다.

## ☁️ 구글 드라이브 자동 연동 (PC ↔ 폰)

- 목록 위 **☁️ 구글 드라이브 연결** 막대를 눌러 연결합니다.
- 연결하면 노트를 저장할 때마다 드라이브의 **앱 전용 공간**(`yongwoo-note-sync.json`)으로 자동 업로드하고,
  다른 기기에서 앱을 열면 최신 노트를 받아 옵니다. 양쪽에서 각각 적은 노트는 **수정 시각을 비교해 합치고**,
  지운 노트는 삭제 표시를 함께 보냅니다.
- 드라이브의 앱 전용 공간은 **내 드라이브 목록에 보이지 않습니다.**
- 상태 표시: `미연결` / `연결됨 · 방금 동기화` / `동기화 중` / `오프라인` / `연결 확인 필요`.
- 첨부는 한 개 8MB·합계 30MB까지 동기화합니다.
- 용우고객관리대장·용우입출금관리대장과 **같은 구글 클라이언트 ID**를 쓰지만, 앱 전용 공간의 파일은 서로 다릅니다.
- 연결하지 않아도 앱은 이 기기에만 저장하며 똑같이 동작합니다.

## 📴 오프라인

서비스 워커(`sw.js`)가 앱 파일을 기기에 보관하므로 **인터넷이 없어도** 목록·작성·수정·인쇄·백업이 모두 됩니다.
구글 로그인·드라이브 요청만 네트워크로 나가며, 오프라인에서는 조용히 이 기기에만 저장합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (HTML + CSS + 자바스크립트가 한 파일) |
| `manifest.webmanifest` | 홈 화면 추가(앱 설치) 설정 — 이름 `용우노트` |
| `sw.js` | 서비스 워커 — 오프라인 보관, 구글 요청은 캐시하지 않음 |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` | 앱 아이콘(파랑·노랑 고대비) |
| `preview-mobile.png` | 목록 화면 예시 (연습용 샘플 데이터) |
| `preview-editor.png` | 편집 화면 예시 (줄노트 + 손글씨 약도) |
| `preview-draw.png`, `preview-print.png`, `preview-print.pdf` | 손글씨 패드, 인쇄 미리보기, 실제 A4 출력 예시 |
| `test/ui-test.py` | 자동 검증 스크립트 (Playwright, 93개 항목) |
| `test/make-icons.py`, `test/make-previews.py` | 아이콘·화면 예시 다시 만들기 |

외부 CDN·서버·라이브러리를 쓰지 않습니다. `index.html` 한 파일만 있어도 목록·작성·검색·인쇄·백업이
모두 동작합니다(이때는 홈 화면 추가·카메라 촬영만 지원되지 않을 수 있습니다).

## 연습용 샘플 노트

☰ → **연습용 샘플 노트 넣기**를 누르면 폴더별 예시 노트 4개가 들어옵니다.
**인물과 일정은 모두 가상**이며, 다 보신 뒤에는 같은 자리에서 **샘플 지우기**로 한 번에 지울 수 있습니다.
실제 고객의 이름·연락처는 노트에 넣지 마세요.
