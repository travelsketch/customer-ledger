# 예외질환 검색기

질병명이나 질병분류코드(KCD) 하나로 **보험사별 간편심사 예외질환·인수기준**을 찾아 비교하는 개인용 웹앱(PWA)입니다.
설계사가 현장에서 쓰던 참고 사이트의 자료만 가져오고, 홍보·타사 브랜딩(성부장 팀, 인스타·카톡 배너, 상담 유도 등)은 모두 뺐습니다.

- 주소: <https://travelsketch.github.io/customer-ledger/yongwoo-disease/>
- 같은 저장소의 다른 앱: 루트(용우고객관리대장) · `yongwoo-cashbook/` · `yongwoo-note/` · `yongwoo-schedule/`

## 무엇을 할 수 있나

| 기능 | 내용 |
| --- | --- |
| 질환 검색 | `대장용종`, `갑상선결절` 같은 병명이나 `D12`, `K63.5` 같은 질병코드를 넣으면 보험사별 기준이 나옵니다. 띄어쓰기·가운뎃점·괄호를 무시하고, 같은 질환의 다른 이름(결장·직장 양성신생물 ↔ 대장용종, 위장염 ↔ 장염 등)도 함께 찾습니다. |
| 자주 찾는 질환 | 검색창 아래 칩(대장용종·갑상선결절·디스크·백내장·장염·자궁근종·하지정맥류·치질·고지혈증·D12)과 최근 검색어. |
| 필터 | 보험 구분(전체 / 손해보험 / 생명보험), 보험사 선택, 필터 초기화. |
| 결과 요약 | “21개 보험사에서 363건”과 보험사별 건수 뱃지. 뱃지를 누르면 그 보험사 카드로 이동하고, 자료에 없는 보험사는 따로 알려 줍니다(가입 불가라는 뜻은 아님). |
| 보험사 카드 | 보험사명 · 손해/생명 뱃지 · 건수, `공통 기준 보기`(자료에 적힌 공통 심사 기준), `원본 이미지`(PDF 캡처로만 온 자료), 질환별 항목표. 4건까지 보이고 `나머지 N건 더 보기`로 펼칩니다. |
| 값 색 구분 | 인수(초록) · 조건·부담보·서류(주황) · 불가·거절(빨강)으로 한눈에 구분합니다. |
| 질환 메모 | 질환마다 메모를 남깁니다. 검색 결과와 인쇄에 함께 나옵니다. |
| 내 자료 | `＋ 내 자료`로 보험사 기준을 직접 추가합니다. 기존 자료는 `수정`을 눌러 **내 수정본**으로 덮어쓸 수 있고, `보험사 원래 자료로 되돌리기`로 되돌립니다. |
| 인쇄 | 지금 검색 결과를 A4 인쇄 미리보기로 뽑습니다(보험사별 건수·공통 기준·메모 포함 여부 선택). |
| 백업 | 내 자료·메모를 JSON 파일 하나로 내려받고 복원합니다. |
| PC·폰 동기화 | `☁️ 구글 드라이브 연결`을 기기마다 한 번 누르면 이후 내 자료·메모가 자동으로 오갑니다(앱 전용 공간, 내 드라이브 목록에는 보이지 않음). |

## 자료

- 보험사가 GA에 배포한 예외질환·인수기준 표(2024~2025년 기준)를 정리한 것입니다.
  **27,030건 · 보험사 22곳**(손해보험 11곳 · 생명보험 11곳) · 자료 묶음 26개.
- KB손보는 표가 아니라 PDF 캡처 그림으로만 와서 글자 검색이 되지 않습니다. 카드의 원본 이미지(10쪽)로 확인합니다.
  농협손보·한화손보·DB생명·라이나생명·한화생명도 원본 이미지를 함께 넣었습니다.
- 원본 사이트의 홍보 문구·상담 링크·얼굴 사진·타사 브랜딩은 넣지 않았습니다.
- 하단 안내: “보험사가 GA에 배포한 예외질환·인수기준 참고 자료이며, 실시간 심사 결과가 아니므로 최종 인수 여부는 각 보험사 언더라이팅 결과를 따릅니다. 개인 참고용으로만 사용하세요.”

## 자료가 어디에 저장되나

- 내 자료: 브라우저 `localStorage` (`yongwooDisease.custom.v1`)
- 메모: `localStorage` (`yongwooDisease.memo.v1`)
- 드라이브를 연결하면: 내 구글 드라이브의 **앱 전용 공간(appDataFolder)** 에 `yongwoo-disease-sync.json` 한 파일로 저장.
  기기별로 한 번 승인하면 되고, 병합은 항목별 수정 시각(`upd`)과 삭제 표시(tombstone)로 맞춥니다.
- 검색 자료(data.js)는 앱에 들어 있어 인터넷이 없어도 열립니다(서비스 워커).

## 파일

```
index.html              화면·코드 전체(외부 CDN 없음, 빌드 결과물)
data.js                 검색 자료(27,030건, 값 사전으로 압축) — index.html 에서 불러옵니다
manifest.webmanifest    PWA 이름·아이콘·테마
sw.js                   서비스 워커(오프라인 열기, 원본 이미지 보관)
icon.svg / icon-192.png / icon-512.png / icon-512-maskable.png
img/                    원본 이미지 자료(WebP, 29장)
build.py                data.js·index.html 조립 스크립트
src/                    원본(data.raw.json, app.css, app.html, core.js, ui.js)
test/                   검증 스크립트(make-icons, smoke, ui-test, drive-test)
preview-mobile.png      휴대폰(412x915) 결과 화면
preview-desktop.png     PC(1280x800) 결과 화면
```

자료를 새로 받아 갱신하려면 `src/data.raw.json`을 바꾸고 `python3 apps/yongwoo-disease/build.py`를 실행합니다.
(자료 파일을 `index.html`에 넣지 않고 `data.js`로 둔 이유: 2.3MB를 HTML에 넣으면 첫 화면이 늦게 뜹니다.
같은 사이트 안의 파일이라 외부 CDN은 없습니다.)
