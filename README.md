# 용우고객관리대장 (휴대폰 웹앱)

보험 상담용 고객 대장을 안드로이드폰에서 쓰는 앱입니다. 고객 정보와 가입보험을 입력하고,
찾고, 인쇄하고, 백업할 수 있습니다. 자료는 기본적으로 **이 기기의 브라우저에만** 저장되며
어디로도 보내지 않습니다. 원하면 **구글 드라이브 자동 연동**을 켜서 PC와 폰의 자료를 맞출 수
있습니다(내 드라이브의 앱 전용 공간 `appDataFolder`만 사용). 인터넷 없이도 열립니다.

## ☁️ 구글 드라이브 자동 연동 (v1.3.0)

- 앱 위쪽 **☁️ 구글 드라이브 연결** 막대(또는 설정 → ☁️ 구글 드라이브)를 눌러 연결합니다.
  구글 계정으로 로그인하고 ‘허용’을 누르면 끝납니다.
- 연결하면 고객·가입보험·첨부 사진/PDF를 저장할 때마다 드라이브의 앱 전용 공간
  (`yongwoo-customer-ledger-sync.json`)으로 자동 업로드하고, 다른 기기에서 앱을 열면 최신
  자료를 받아 옵니다. 두 기기에서 각각 고객을 추가·수정한 경우에는 고객별 수정 시각을 비교해
  **양쪽 자료를 합칩니다**(지운 고객은 삭제 표시를 함께 보내 되살아나지 않게 합니다).
- 상태 표시: `미연결` / `연결됨 · 방금 동기화` / `동기화 중` / `오프라인`. 오프라인이거나
  구글 스크립트를 못 불러오면 앱은 지금처럼 이 기기에만 저장하고 정상 동작합니다.
- 첨부 파일은 한 개 8MB·합계 30MB까지 동기화하며, 넘는 파일은 이 기기에만 남습니다.
- 구글 클라이언트 ID는 앱에 내장되어 있고, 설정의 **고급 설정**에서 다른 ID로 바꿀 수 있습니다.
- 구글 클라우드 프로젝트 `yongwoo-ledger-sync` / OAuth 동의 화면은 **테스트(Testing)** 상태이며,
  테스트 사용자로 등록한 계정만 연결됩니다(현재 `bluewind312@gmail.com`).

## 휴대폰에서 쓰는 방법

1. **웹에 올려서 쓰기(권장)** — 이 폴더를 그대로 HTTPS 주소에 올립니다(GitHub Pages, Netlify
   같은 정적 호스팅이면 됩니다). 폰 크롬·삼성 인터넷에서 주소를 열고 메뉴의
   **‘홈 화면에 추가’**를 누르면 앱처럼 전체 화면으로 열립니다.
2. **파일로 받아 쓰기** — `index.html`을 폰에 저장해 열면 바로 쓸 수 있습니다. 이 경우 홈 화면
   추가·오프라인 설치는 지원되지 않고, 브라우저 기록을 지우면 자료도 지워집니다.
3. **PC에서 쓰기** — `index.html`을 더블클릭해 열고, 인쇄는 `인쇄 미리보기 → 인쇄`에서 합니다.

## 쓰는 법

- **고객 추가**: 아래 `＋ 고객 추가` → 이름(필수)·생년월일·전화·주소·차량번호·비고 입력.
  생년월일은 `560907`처럼 6자리로 넣어도 `1956-09-07`로 바뀝니다.
- **가입보험**: 한 고객에 여러 건을 넣을 수 있습니다. `＋ 보험 추가`로 늘리고 `삭제`로 줄입니다.
  월보험료를 넣으면 고객별 합계와 전체 합계가 저절로 계산됩니다.
- **찾기**: 위 검색창에 이름·전화번호(뒷자리도 가능)·주소·차량번호·보험회사·상품명을 넣으면
  바로 걸러집니다. `납입 임박`(7일 이내), `만기 임박`(90일 이내), `보험 없음` 버튼과 정렬을 함께 쓸 수 있습니다.
- **전화 걸기**: 목록이나 상세 화면의 파란 전화번호를 누르면 바로 전화가 걸립니다.
- **계산기**: 오른쪽 위 🧮 를 누르면 화면 아래에서 계산기가 올라옵니다(사칙연산·`%`·`C`·`⌫`).
  고객 입력·수정 화면에서는 각 보험의 `월보험료(원)` 칸 옆 🧮 로 열면, 계산한 결과를 `보험료에 넣기`
  한 번으로 그 칸에 바로 채울 수 있습니다(합계도 즉시 다시 계산).
- **사진·PDF 첨부**: 고객 입력·수정 화면 아래 `첨부 파일`에서 `＋ 사진·PDF`(여러 개) 또는
  `📷 카메라 촬영`(그 자리에서 촬영)을 누릅니다. 청약서·신분증·영수증·증권 사진/PDF를 붙일 수 있고,
  사진은 저장할 때 긴 변 1600px·JPEG(품질 0.8)로 자동으로 줄어듭니다(이미 작은 사진은 원본 그대로,
  PDF는 손대지 않음). 파일은 `localStorage`가 아니라 **IndexedDB**에 보관되어 5MB 제한이 없습니다.
  상세 화면에서는 사진 썸네일 + `크게` 보기, PDF는 `열기`·`저장`이 되고 `✕`로 지울 수 있습니다.
- **인쇄**: `선택`을 눌러 인쇄할 고객만 체크하거나 `전체 인쇄`를 누르면 A4 양식 미리보기가 뜹니다.
  미리보기에서 `인쇄`를 누르면 출력됩니다(제목·출력일시·총 인원·총 월보험료·첨부 개수 포함).
  `첨부 사진도 인쇄`를 체크하면 고객별 첨부 사진이 지면에 함께 들어갑니다.
  인쇄 대화상자에서 `머리글과 바닥글`을 끄면 주소·날짜가 찍히지 않아 더 깔끔합니다.
- **백업·내보내기**: 오른쪽 위 ⚙ → `JSON 백업 파일 받기`. 폰을 바꾸거나 기록을 지울 때
  `JSON 백업 불러오기`로 되살립니다. `엑셀 파일(.xlsx)로 받기`는 `고객목록`·`가입보험` 두 시트로
  바로 열리고(금액 서식·머리글 고정), `구글 시트용 CSV 받기`는 한글이 깨지지 않는 UTF-8(BOM)
  CSV를 받은 뒤 구글 시트에서 여는 방법을 안내합니다. 첨부 사진·PDF 파일 자체는 JSON 백업에
  들어가지 않습니다(이 기기의 IndexedDB에만 보관).
- **되돌리기**: 삭제·전체 비우기 뒤 화면 아래 `되돌리기`를 누르면 원래대로 돌아옵니다.

## 검증

`test/ui-test.py`는 실제 크로미움을 412×915 모바일 화면으로 띄워 등록·검색·수정·선택 인쇄·
전체 인쇄·삭제·백업·복원·오프라인 동작을 자동으로 확인하고 스크린샷을 다시 만듭니다.
`test/ui-test-v12.py`는 계산기, 사진/PDF 첨부(카메라 input·자동 압축·IndexedDB), 인쇄 사진 포함,
`.xlsx`(openpyxl·zipfile로 실제 파일 검증), 구글시트용 CSV를 함께 확인합니다.
서버는 스크립트 안에서만 뜨고 끝나면 종료됩니다.

```bash
pip install playwright openpyxl pillow && playwright install chromium
python3 test/ui-test.py
python3 test/ui-test-v12.py
```

최근 결과: `ui-test.py` 95/95, `ui-test-v12.py` 115/115 통과 (412×915 모바일 화면, 콘솔 오류 0).
