# 용우입출금관리대장 (휴대폰 웹앱)

입금·출금을 적고, 계산기로 금액을 계산하고, 영수증 사진·계약서 PDF를 붙이고, A4로 인쇄하고,
엑셀(.xlsx)·구글 시트용 CSV·JSON 백업으로 내보내는 휴대폰 앱입니다.
자료는 기본적으로 **이 기기의 브라우저 저장소(IndexedDB)에만** 저장되며 어디로도 보내지
않습니다. 원하면 **구글 드라이브 자동 연동**으로 PC와 폰의 기록을 맞출 수 있습니다.
인터넷이 없어도 열립니다.

## ☁️ 구글 드라이브 자동 연동 (v1.1.0)

- 화면 위 **☁️ 구글 드라이브 연결** 막대(또는 설정 → ☁️ 구글 드라이브)를 눌러 연결합니다.
- 연결하면 기록·첨부(영수증 사진·PDF)를 저장할 때마다 드라이브의 앱 전용 공간
  (`yongwoo-cashbook-sync.json`)으로 자동 업로드하고, 다른 기기에서 열면 최신 기록을 받아
  옵니다. 양쪽에서 각각 입력한 기록은 **수정 시각을 비교해 합칩니다**(지운 기록은 삭제 표시를
  함께 보냅니다).
- 상태 표시: `미연결` / `연결됨 · 방금 동기화` / `동기화 중` / `오프라인`.
- 용우고객관리대장과 **같은 구글 클라이언트 ID**를 쓰며, 앱 전용 공간의 파일은 서로 다릅니다.
- 첨부는 한 개 8MB·합계 30MB까지 동기화합니다.

- 주소: **https://travelsketch.github.io/customer-ledger/yongwoo-cashbook/**
- 폰에서 크롬·삼성 인터넷으로 위 주소를 연 뒤 메뉴의 **‘홈 화면에 추가’**를 누르면 앱처럼 전체 화면으로 열립니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (HTML + CSS + 자바스크립트가 한 파일) |
| `manifest.webmanifest` | 홈 화면 추가(앱 설치) 설정 |
| `sw.js` | 서비스 워커 — 오프라인에서도 열리도록 파일 보관 |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` | 앱 아이콘 |
| `preview-mobile.png` | 목록 화면 예시 (연습용 샘플 데이터) |
| `preview-print.png`, `preview-print.pdf` | 인쇄 미리보기 화면과 실제 A4 출력 예시 |
| `screenshot-form.png`, `screenshot-form-files.png`, `screenshot-detail.png`, `screenshot-calculator.png` | 입력·첨부·상세·계산기 화면 예시 |
| `test/ui-test.py` | 자동 검증 스크립트 (Playwright, 145개 항목) |
| `test/make-previews.py`, `test/make-icons.py` | 화면 예시·아이콘 다시 만들기 |

외부 CDN·서버·라이브러리를 쓰지 않습니다. `index.html` 한 파일만 있어도 목록·입력·검색·인쇄·
백업이 모두 동작합니다(이때는 홈 화면 추가·카메라 촬영만 지원되지 않을 수 있습니다).

## 쓰는 법

- **입력** — 아래 `＋ 입출금 입력` → 구분(입금/출금)·날짜·금액·분류·거래처·내용·결제수단·메모.
  금액은 숫자만 넣으면 콤마가 저절로 붙습니다. 분류는 단추를 고르거나 직접 적을 수 있습니다.
- **요약** — 위에서 `이번 달 / 지난 달 / 전체 / 직접`을 고르면 그 기간의 **총 입금·총 출금·잔액**을
  큰 글씨로 보여 줍니다. 검색·구분 필터는 목록에만 적용되고 합계는 기간 기준입니다.
- **계산기** — 🧮 버튼(위쪽·아래쪽·금액 칸 옆)으로 열고 계산한 뒤 **금액에 바로 넣기**를 누르면
  금액 칸에 들어갑니다. `+ − × ÷ % C ← =` 지원, 계산식이 함께 표시됩니다.
- **사진·PDF** — 입력 화면에서 `🖼 사진·PDF 고르기` 또는 `📷 카메라 촬영`(갤럭시 카메라가 바로 열림).
  여러 개를 붙일 수 있고, 목록에 📎 개수와 첫 사진 썸네일이 보입니다. 상세에서 사진은 눌러 크게,
  PDF는 눌러 열기·내려받기.
  - 사진은 저장할 때 **긴 변 최대 1600px, JPEG 품질 80%**로 자동으로 줄여 보관합니다.
    원본이 이미 작고 가벼우면(긴 변 1600px 이하 + 1MB 이하) 그대로 두고, 줄인 결과가 원본보다
    크면 원본을 씁니다. PDF는 압축하지 않고 그대로 보관합니다. 파일 목록에 `13.4MB→917KB`처럼
    압축 후 용량이 표시됩니다.
- **수정·삭제** — 목록에서 한 건을 누르면 상세가 열리고 `수정`·`삭제`·`인쇄`를 할 수 있습니다.
  삭제하면 화면 아래 `되돌리기`가 잠깐 나타납니다.
- **검색** — 내용·거래처·분류·메모·결제수단·금액을 한 번에 찾습니다(띄어쓰기로 여러 단어 가능).
- **인쇄** — `🖨 인쇄`는 지금 화면(기간·검색·구분) 그대로, `선택`을 누르면 체크한 것만 인쇄합니다.
  미리보기에서 `첨부 사진 함께 인쇄`, `메모 포함`을 켜고 끌 수 있습니다. A4 한 장에 제목
  `용우입출금관리대장`, 기간, 출력일시, 건별 표, 총 입금/총 출금/잔액, 첨부 개수가 들어갑니다.
  인쇄 대화상자에서 `머리글과 바닥글`을 끄면 주소·날짜가 찍히지 않아 더 깔끔합니다.
- **엑셀** — `⬇ 내보내기 → 엑셀 파일(.xlsx)`: 엑셀·한셀에서 바로 열립니다. 날짜는 날짜 서식,
  금액은 숫자 서식, 메모·첨부파일명까지 들어가고 합계 행과 틀 고정이 있습니다.
  파일 이름 `용우입출금관리대장_YYYY-MM-DD.xlsx`.
- **구글 시트** — `⬇ 내보내기 → 구글 시트용 CSV`(UTF-8 BOM, 한글 안 깨짐) → 구글 시트에서
  `파일 → 가져오기 → 업로드`로 고르고 `쉼표/UTF-8` 그대로 `데이터 가져오기`.
  파일 이름 `용우입출금관리대장_구글시트용_YYYY-MM-DD.csv`.
- **백업** — `⬇ 내보내기 → 전체 백업 파일(JSON)`은 사진·PDF까지 한 파일에 담습니다.
  폰을 바꾸기 전에는 꼭 받아 두세요. `백업 불러오기`에서 `합치기`(기존에 더함) 또는
  `덮어쓰기`(기존을 지우고 복원)를 고를 수 있습니다.
- **연습용 샘플** — 설정(⚙)에서 `샘플 데이터 넣기`. 샘플은 목록에 `연습` 표시가 붙고
  `샘플만 지우기`로 실제 기록과 구분해 지울 수 있습니다.

## 자료 보관 주의

기록과 첨부는 이 기기의 브라우저(IndexedDB)에만 있습니다. 브라우저의 **방문 기록·사이트 데이터
삭제**, 시크릿 모드 사용, 앱 삭제 시 함께 지워질 수 있으니, 중요한 기록은 가끔 엑셀/JSON으로
백업해 두시기 바랍니다. 서버로 보내지 않으므로 다른 기기와 자동으로 맞춰지지 않습니다.

## 검증

`test/ui-test.py`는 실제 크로미움을 412×915 모바일 화면으로 띄워 145개 항목을 확인합니다:
입력·수정·삭제·되돌리기, 금액 콤마, 검색·구분·기간 필터와 합계, 계산기와 금액 넣기,
사진 2장+PDF 첨부와 IndexedDB 저장·복원, 사진 크게 보기·PDF 열기, 사진 자동 압축(2600×1800·13MB
→ 1600×1108·917KB)과 PDF 무압축, 인쇄 미리보기·선택 인쇄·사진 모아 인쇄·A4 PDF, `.xlsx` 구조
(openpyxl로 셀 값·서식·병합·틀 고정 확인), 구글시트 CSV(BOM·따옴표), JSON 백업/복원(첨부 바이트
일치), 샘플 넣기/지우기, 오프라인 실행, 외부 요청 0건, 콘솔 오류 0건.

```bash
pip install playwright openpyxl pillow && playwright install chromium
python3 test/ui-test.py        # 결과: 145/145 통과
python3 test/make-previews.py  # 화면 예시 사진 다시 만들기
```
